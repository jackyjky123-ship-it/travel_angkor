# Angkor Travel – Siem Reap

![Angkor Travel Preview](https://images.unsplash.com/photo-1600832049888-028c772cba24?ixlib=rb-4.0.3&auto=format&fit=crop&w=1200&q=80)

Welcome to **Angkor Travel**, a premium, high-end travel booking platform dedicated to providing the most authentic and crowd-evading tours of the majestic Angkor Wat temple complex.

Designed with a modern, dark-mode aesthetic and fluid animations, this web application serves as a luxury gateway for travelers looking to experience the Khmer Empire through the eyes of certified native historians.

## ✨ Key Features

- **Immersive User Interface:** A stunning, dark-mode design with advanced glassmorphism effects and modern typography.
- **Fluid Animations:** Powered by `framer-motion`, featuring staggered scroll reveals, fading modal transitions, and an infinite auto-scrolling pillar carousel.
- **Signature Tour Experiences:** Showcasing curated packages like the "Angkor Sunrise VIP" and "Khmer Empire Grand Circuit".
- **The Local Difference:** Highlighting responsible tourism, community funding, and crowd-avoidance routing (e.g., East Gate entries).
- **Responsive Design:** Completely optimized for mobile, tablet, and desktop viewing.

## 🛠 Tech Stack

- **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/jackyjky123-ship-it/travel_angkor.git
   cd travel_angkor
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📂 Project Structure

The project has been organized for scalability and clean architecture:
- `src/components/`: Reusable, modular UI components (`Navbar`, `FadeIn`, `HeroSection`, `WhyUsSection`).
- `src/pages/`: Page-level components that compose sections together (`HomePage`, `TourPage`, `GuidePage`, `ReviewPage`).
- `src/data/`: Centralized content and state data (e.g., `toursData.ts`).
- `src/index.css`: Global styling overrides and font declarations.

## 🌿 Our Mission

We believe that to truly understand the majesty of the Khmer Empire, one must see it through the eyes of those who grew up in the shadow of its temples. 5% of bookings directly support local village initiatives, ensuring that tourism benefits the native communities of Siem Reap.
